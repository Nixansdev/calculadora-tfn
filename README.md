# Calculadora T.F.N.

Calculadora de conversiones entre sistemas de numeración (decimal, binario, octal y hexadecimal) que muestra el desarrollo completo paso a paso: divisiones sucesivas, T.F.N. y agrupación de bits, igual que en clase.

Creada por **Abdu** · IES Leopoldo Queipo.

## Desarrollo

Necesitas Node.js y npm (o bun).

```sh
npm install
npm run dev
```

## Construida con

- TanStack Start
- TypeScript
- React
- Tailwind CSS
